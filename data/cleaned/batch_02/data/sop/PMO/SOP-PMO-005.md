## Purpose

This SOP defines the standard procedure for **project escalation procedure** within the Project Management / PMO department at MK-INFINITE-AI PRIVATE LIMITED, ensuring the process is followed consistently, is auditable, and meets the department's service expectations.

## Scope

This procedure applies to all Project Managers and any employee across MK-Infinite-AI who needs to initiate a **Project Escalation** request. It covers the full workflow from initiation through to closure in MK-PMTrack.

## Applicable Roles

- Primary actor: **Project Manager**
- Approver: **Program Manager**
- System of record: **MK-PMTrack**

## Preconditions

- The requester has an active MK-Infinite-AI account and access to MK-PMTrack.
- Documenting the blocker and attempted resolution steps must be available before starting this procedure.

## Required Information

- Employee ID and department
- Details of the project escalation being requested
- Any supporting documentation required for approval

## Procedure

**Step 1:** the Project Manager confirms the exact symptom, when it started, and whether it affects one system or several.

**Step 2:** the Project Manager performs the standard first-line check: documenting the blocker and attempted resolution steps.

**Step 3:** If the issue persists, the Project Manager applies the documented workaround for this issue type.

**Step 4:** the Project Manager checks whether the issue is isolated to their own account/device or is affecting other users too.

**Step 5:** If still unresolved, the Project Manager raises a ticket in MK-PMTrack categorised under 'Project Escalation', attaching screenshots or error logs.

**Step 6:** The assigned specialist reproduces the issue, diagnoses the root cause, and applies a fix or a temporary workaround.

**Step 7:** the Project Manager confirms the fix works; the ticket is closed in MK-PMTrack with the root cause logged. Escalations unresolved after 48 hours reach the PMO Director.

## Expected Result

The project escalation is completed, logged in MK-PMTrack, and the requester is notified of the outcome. The record remains available in MK-PMTrack for future reference and audit.

## Exceptions

- Escalations unresolved after 48 hours reach the PMO Director.
- Requests that do not meet the preconditions above are returned to the requester with an explanation rather than being rejected outright.

## Escalation Procedure

If the request is not actioned within the expected timeframe, escalate in this order: Project Coordinator → Project Manager → PMO Lead → PMO Director. Escalations should reference the SOP-PMO-005 document ID and the relevant ticket/request number.
