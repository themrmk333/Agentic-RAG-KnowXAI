## Scenario
The designated approver (Facilities Manager) is on leave, travel, or otherwise unreachable within the normal response window, but the admin onboarding cannot wait for their return.

## Deviation Procedure

1. Admin Team Lead confirms the Facilities Manager has an active out-of-office status in MK-FacilitiesDesk or MK-HRMS before invoking this path.
2. Admin Team Lead identifies the Facilities Manager's designated delegate — typically the next role up the escalation chain (Facilities Executive -> Facilities Coordinator -> Facilities Manager -> Head of Administration) — as recorded in MK-FacilitiesDesk.
3. Admin Team Lead resubmits or flags the existing request in MK-FacilitiesDesk, tagging it 'Delegate Approval Required' with the reason.
4. The delegate reviews the request using the same criteria the original Facilities Manager would apply, and either approves, rejects, or requests clarification.
5. Once the Facilities Manager returns, they are notified of the delegate decision for their records; they may flag it for a follow-up review within 5 business days if something looks inconsistent with policy.
6. MK-FacilitiesDesk logs both the delegate's identity and the reason for delegation on the request record for audit purposes.

## Important Note
Delegation does not apply to Administration Onboarding Procedure decisions explicitly reserved for the Facilities Manager by policy (e.g., anything requiring named signing authority); those must wait for the Facilities Manager's return or be routed to the next level up, not a lateral delegate.

## Escalation
If this edge case procedure itself cannot be completed, escalate through: Facilities Executive -> Facilities Coordinator -> Facilities Manager -> Head of Administration.
