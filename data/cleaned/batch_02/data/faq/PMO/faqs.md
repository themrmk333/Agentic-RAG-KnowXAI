## FAQ-PMO-001: How do I complete: Project Creation and Charter Approval Procedure?
**Category:** Project Initiation | **Difficulty:** Basic | **Access Level:** general | **Roles:** Project Manager, PMO Director

**Short Answer:** Follow the 7-step Project Creation and Charter Approval Procedure procedure in MK-PMTrack, starting with the SOP-PMO-001 SOP.

**Detailed Answer:** The Project Creation and Charter Approval Procedure process (SOP-PMO-001) is owned by the Project Management / PMO department. The project manager initiates the request in MK-PMTrack and PMO Director is responsible for approval/sign-off. Projects without an approved charter cannot be resourced in MK-PMTrack.

**Step-by-step:**
1. the Project Manager logs into MK-PMTrack and navigates to the 'Project Charter' section.
2. the Project Manager selects 'New Project Charter' and enters the required details, including objectives, scope, budget estimate, and sponsor sign-off.
3. the Project Manager attaches any supporting documentation and reviews the entry for accuracy before submitting.
4. the Project Manager submits the Project Charter; MK-PMTrack automatically routes it to the PMO Director for review.
5. The PMO Director reviews the request against company policy and either approves, rejects, or returns it for clarification.
6. On approval, MK-PMTrack updates the status to 'Approved' and notifies the Project Manager by email/in-app notification.
7. The approved Project Charter is processed and the record is retained in MK-PMTrack for audit purposes. Projects without an approved charter cannot be resourced in MK-PMTrack.

**Related Documents:** SOP-PMO-001
**Escalation Path:** Project Coordinator -> Project Manager -> PMO Lead -> PMO Director

## FAQ-PMO-005: How do I complete: Project Escalation Procedure?
**Category:** Escalation | **Difficulty:** Basic | **Access Level:** employee | **Roles:** Project Manager, Program Manager

**Short Answer:** Follow the 7-step Project Escalation Procedure procedure in MK-PMTrack, starting with the SOP-PMO-005 SOP.

**Detailed Answer:** The Project Escalation Procedure process (SOP-PMO-005) is owned by the Project Management / PMO department. The project manager initiates the request in MK-PMTrack and Program Manager is responsible for approval/sign-off. Escalations unresolved after 48 hours reach the PMO Director.

**Step-by-step:**
1. the Project Manager confirms the exact symptom, when it started, and whether it affects one system or several.
2. the Project Manager performs the standard first-line check: documenting the blocker and attempted resolution steps.
3. If the issue persists, the Project Manager applies the documented workaround for this issue type.
4. the Project Manager checks whether the issue is isolated to their own account/device or is affecting other users too.
5. If still unresolved, the Project Manager raises a ticket in MK-PMTrack categorised under 'Project Escalation', attaching screenshots or error logs.
6. The assigned specialist reproduces the issue, diagnoses the root cause, and applies a fix or a temporary workaround.
7. the Project Manager confirms the fix works; the ticket is closed in MK-PMTrack with the root cause logged. Escalations unresolved after 48 hours reach the PMO Director.

**Related Documents:** SOP-PMO-005
**Escalation Path:** Project Coordinator -> Project Manager -> PMO Lead -> PMO Director

**Short Answer:** Yes. Project Management / PMO knowledge is retrievable company-wide; only documents marked restricted or management-level require extra authorization.

**Detailed Answer:** MK-Infinite-AI's knowledge base does not gate department knowledge behind the requester's own department. An employee from any department can ask a Project Management / PMO question (for example, an IT employee asking about the leave policy). Access is instead controlled per-document via the 'access_level' and 'allowed_departments' metadata, so general employee-facing knowledge remains available company-wide while restricted or management-level documents stay protected.

**Escalation Path:** Project Coordinator -> Project Manager -> PMO Lead -> PMO Director
