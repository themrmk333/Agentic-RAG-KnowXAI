## Common Mistakes to Avoid

- Raising IT requests verbally instead of logging a ticket in MK-ServiceDesk, which delays tracking.
- Installing unapproved software without submitting a Software Installation Request.
- Not reporting a lost device immediately, which delays remote wipe and increases data risk.
