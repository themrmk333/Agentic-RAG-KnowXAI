## Situation
R&D Manager submits a r&d onboarding request in MK-Labs that is missing required supporting information, or contains incorrect details (wrong amount, wrong employee, wrong date).

## Detection
The R&D Director reviewing the request in MK-Labs notices a required field is blank, a required attachment is missing, or the details don't reconcile with other records (e.g., an amount that doesn't match the attached receipt).

## Decision Criteria
The R&D Director decides whether the gap is minor enough to request a quick correction, or serious enough that the request should be rejected outright and resubmitted from scratch.

## Steps

1. The R&D Director does not approve or silently correct the request themselves; they return it to R&D Manager in MK-Labs with a specific note on what's missing or wrong.
2. R&D Manager is notified automatically and has a defined window (typically 5 business days) to correct and resubmit before the request is auto-closed as abandoned.
3. R&D Manager corrects the specific issue identified — not a wholesale re-submission — and resubmits, keeping the same request thread rather than opening a new one.
4. The R&D Director reviews only the corrected fields on resubmission rather than re-reviewing the entire request from zero, to keep turnaround fast.
5. If the same requester repeatedly submits incomplete requests (3+ times in a quarter), the R&D Director flags this to the requester's manager for a coaching conversation.
6. Once complete and accurate, the request proceeds through the standard approval procedure in SOP-RND-010.
