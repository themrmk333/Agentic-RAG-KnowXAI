**Department:** Marketing

## Situation
MK-MarketHub is down, in scheduled maintenance, or otherwise unreachable, but the agency engagement request genuinely cannot wait until the system is restored.

## Detection
Marketing Manager attempts to log into MK-MarketHub and receives a system-unavailable error, or has received a maintenance notification covering the relevant window (see the Communications archive).

## Decision Criteria
Marketing Manager first checks whether the request is time-sensitive enough to justify an off-system workaround, or whether it can simply wait for MK-MarketHub to be restored (the default expectation).

## Steps

1. Marketing Manager confirms MK-MarketHub is genuinely unavailable (not just a personal connectivity issue) by checking with a colleague or the IT status page.
2. For non-urgent agency engagement request requests, Marketing Manager waits for MK-MarketHub to be restored and submits normally — this is the default and preferred path.
3. For genuinely urgent requests, Marketing Manager documents the request details (who, what, why, when) in an email to the Marketing Director instead of the system.
4. The Marketing Director reviews the emailed request using the same criteria they would apply inside MK-MarketHub, and replies with an approval/rejection decision in writing.
5. Once MK-MarketHub is restored, Marketing Manager or the Marketing Director re-enters the request and its outcome into MK-MarketHub retroactively, referencing the original email for the audit trail.
6. MK-MarketHub's record is tagged 'Entered Retroactively — System Outage' so reporting doesn't mistake the entry date for the actual request date.

## Responsible Role
Marketing Manager

## Approval
Marketing Director

## Escalation
Marketing Executive -> Marketing Team Lead -> Marketing Manager -> Marketing Director

## Expected Result
The agency engagement request is actioned without waiting for system restoration when genuinely urgent, while still ending up fully and correctly recorded in MK-MarketHub once it's back online.
