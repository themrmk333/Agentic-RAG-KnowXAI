## Common Mistakes to Avoid

- Forwarding a suspicious email instead of using the Report Phishing button, which can spread the payload.
- Requesting broad 'any-any' firewall rules instead of scoped access.
- Delaying incident reporting while attempting to self-diagnose a suspected compromise.
