# Administration / Facilities — Advanced FAQs (Edge Cases, Comparisons, Policy Interpretation)

## FAQADV-ADMIN-001: New Employee Workspace Setup Procedure: What happens if Office Manager is unavailable to approve a workspace setup?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Route it to the Office Manager's delegate (typically the next role up the escalation chain) via MK-FacilitiesDesk, tagged 'Delegate Approval Required'; the Office Manager is notified on return and can flag it for review within 5 business days if needed.

**Related Documents:** SOP-ADMIN-001-EDGE-A
---

## FAQADV-ADMIN-002: New Employee Workspace Setup Procedure: Can a workspace setup be expedited in a genuine emergency?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Yes, via the expedited path: get verbal pre-approval from the Office Manager directly, proceed with the minimum necessary action, then file the formal request in MK-FacilitiesDesk within 24 hours marked 'Emergency — Retroactive Approval'.

**Related Documents:** SOP-ADMIN-001-EDGE-B
---

## FAQADV-ADMIN-003: New Employee Workspace Setup Procedure: What do I do if MK-FacilitiesDesk is down and I need to submit a workspace setup?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Non-urgent requests should wait for MK-FacilitiesDesk to be restored. For genuinely urgent cases, email the Office Manager directly with the request details; once MK-FacilitiesDesk is back, enter the request and outcome retroactively, tagged 'Entered Retroactively — System Outage'.

**Related Documents:** SOP-ADMIN-001-EDGE-C
---

## FAQADV-ADMIN-004: New Employee Workspace Setup Procedure: What happens if my workspace setup request is rejected, or I accidentally submit it twice?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Rejections always come with a documented reason in MK-FacilitiesDesk — correct the issue and resubmit, or escalate once if you disagree. Duplicates are flagged automatically and reconciled by keeping the original and closing the duplicate with a cross-reference.

**Related Documents:** SOP-ADMIN-001-EDGE-D
---

## FAQADV-ADMIN-005: New Employee Workspace Setup Procedure: What happens if my workspace setup submission is missing required documentation?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** The Office Manager returns the request in MK-FacilitiesDesk with a specific note on what's missing rather than approving or fixing it themselves; you have about 5 business days to correct and resubmit through the same request thread.

**Related Documents:** SOP-ADMIN-001-EDGE-E
---

## FAQADV-ADMIN-026: If I find an old reference to the Facility Access Policy that seems to disagree with what's current, which one is right?
**Category:** Policy Interpretation | **Difficulty:** Intermediate | **Access Level:** general

**Answer:** The current version, POL-ADMIN-001, is always authoritative going forward. If an older cached or printed copy of the Facility Access Policy disagrees with it, treat the current document as correct and check the POL-ADMIN-001-HISTORY document to understand exactly what changed and when.

## FAQADV-ADMIN-028: What's the difference between the standard New Employee Workspace Setup Procedure process and the emergency/expedited version?
**Category:** Comparison | **Difficulty:** Intermediate | **Access Level:** employee

**Answer:** The standard path (SOP-ADMIN-001) goes through Office Manager via MK-FacilitiesDesk in the normal order. The expedited path (SOP-ADMIN-001-EDGE-B) is only for genuine emergencies: it requires verbal pre-approval first, immediate action, then retroactive formal filing within 24 hours — and repeated use of the expedited path for the same request type triggers a review.

**Related Documents:** SOP-ADMIN-001, SOP-ADMIN-001-EDGE-B
