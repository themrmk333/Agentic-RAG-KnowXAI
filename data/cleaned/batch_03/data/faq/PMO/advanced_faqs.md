# Project Management / PMO — Advanced FAQs (Edge Cases, Comparisons, Policy Interpretation)

## FAQADV-PMO-001: Project Creation and Charter Approval Procedure: What happens if PMO Director is unavailable to approve a project charter?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Route it to the PMO Director's delegate (typically the next role up the escalation chain) via MK-PMTrack, tagged 'Delegate Approval Required'; the PMO Director is notified on return and can flag it for review within 5 business days if needed.

**Related Documents:** SOP-PMO-001-EDGE-A
---

## FAQADV-PMO-002: Project Creation and Charter Approval Procedure: Can a project charter be expedited in a genuine emergency?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Yes, via the expedited path: get verbal pre-approval from the PMO Director directly, proceed with the minimum necessary action, then file the formal request in MK-PMTrack within 24 hours marked 'Emergency — Retroactive Approval'.

**Related Documents:** SOP-PMO-001-EDGE-B
---

## FAQADV-PMO-003: Project Creation and Charter Approval Procedure: What do I do if MK-PMTrack is down and I need to submit a project charter?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Non-urgent requests should wait for MK-PMTrack to be restored. For genuinely urgent cases, email the PMO Director directly with the request details; once MK-PMTrack is back, enter the request and outcome retroactively, tagged 'Entered Retroactively — System Outage'.

**Related Documents:** SOP-PMO-001-EDGE-C
---

## FAQADV-PMO-004: Project Creation and Charter Approval Procedure: What happens if my project charter request is rejected, or I accidentally submit it twice?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Rejections always come with a documented reason in MK-PMTrack — correct the issue and resubmit, or escalate once if you disagree. Duplicates are flagged automatically and reconciled by keeping the original and closing the duplicate with a cross-reference.

**Related Documents:** SOP-PMO-001-EDGE-D
---

## FAQADV-PMO-005: Project Creation and Charter Approval Procedure: What happens if my project charter submission is missing required documentation?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** The PMO Director returns the request in MK-PMTrack with a specific note on what's missing rather than approving or fixing it themselves; you have about 5 business days to correct and resubmit through the same request thread.

**Related Documents:** SOP-PMO-001-EDGE-E
---

## FAQADV-PMO-026: If I find an old reference to the Project Change Management Policy that seems to disagree with what's current, which one is right?
**Category:** Policy Interpretation | **Difficulty:** Intermediate | **Access Level:** employee

**Answer:** The current version, POL-PMO-001, is always authoritative going forward. If an older cached or printed copy of the Project Change Management Policy disagrees with it, treat the current document as correct and check the POL-PMO-001-HISTORY document to understand exactly what changed and when.

**Related Documents:** POL-PMO-001, POL-PMO-001-HISTORY
---

## FAQADV-PMO-027: What's the difference between the standard Project Creation and Charter Approval Procedure process and the emergency/expedited version?
**Category:** Comparison | **Difficulty:** Intermediate | **Access Level:** employee

**Answer:** The standard path (SOP-PMO-001) goes through PMO Director via MK-PMTrack in the normal order. The expedited path (SOP-PMO-001-EDGE-B) is only for genuine emergencies: it requires verbal pre-approval first, immediate action, then retroactive formal filing within 24 hours — and repeated use of the expedited path for the same request type triggers a review.

**Related Documents:** SOP-PMO-001, SOP-PMO-001-EDGE-B
