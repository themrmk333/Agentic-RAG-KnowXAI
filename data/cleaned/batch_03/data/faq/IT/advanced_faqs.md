# IT Support / Information Technology — Advanced FAQs (Edge Cases, Comparisons, Policy Interpretation)

## FAQADV-IT-001: Password Reset Procedure: What happens if IT Support Engineer is unavailable to approve a account access?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Route it to the IT Support Engineer's delegate (typically the next role up the escalation chain) via MK-ServiceDesk, tagged 'Delegate Approval Required'; the IT Support Engineer is notified on return and can flag it for review within 5 business days if needed.

**Related Documents:** SOP-IT-001-EDGE-A
---

## FAQADV-IT-002: Password Reset Procedure: Can a account access be expedited in a genuine emergency?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Yes, via the expedited path: get verbal pre-approval from the IT Support Engineer directly, proceed with the minimum necessary action, then file the formal request in MK-ServiceDesk within 24 hours marked 'Emergency — Retroactive Approval'.

**Related Documents:** SOP-IT-001-EDGE-B
---

## FAQADV-IT-003: Password Reset Procedure: What do I do if MK-ServiceDesk is down and I need to submit a account access?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Non-urgent requests should wait for MK-ServiceDesk to be restored. For genuinely urgent cases, email the IT Support Engineer directly with the request details; once MK-ServiceDesk is back, enter the request and outcome retroactively, tagged 'Entered Retroactively — System Outage'.

**Related Documents:** SOP-IT-001-EDGE-C
---

## FAQADV-IT-004: Password Reset Procedure: What happens if my account access request is rejected, or I accidentally submit it twice?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Rejections always come with a documented reason in MK-ServiceDesk — correct the issue and resubmit, or escalate once if you disagree. Duplicates are flagged automatically and reconciled by keeping the original and closing the duplicate with a cross-reference.

**Related Documents:** SOP-IT-001-EDGE-D
---

## FAQADV-IT-005: Password Reset Procedure: What happens if my account access submission is missing required documentation?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** The IT Support Engineer returns the request in MK-ServiceDesk with a specific note on what's missing rather than approving or fixing it themselves; you have about 5 business days to correct and resubmit through the same request thread.

**Related Documents:** SOP-IT-001-EDGE-E
---

## FAQADV-IT-031: What's the difference between the standard Password Reset Procedure process and the emergency/expedited version?
**Category:** Comparison | **Difficulty:** Intermediate | **Access Level:** employee

**Answer:** The standard path (SOP-IT-001) goes through IT Support Engineer via MK-ServiceDesk in the normal order. The expedited path (SOP-IT-001-EDGE-B) is only for genuine emergencies: it requires verbal pre-approval first, immediate action, then retroactive formal filing within 24 hours — and repeated use of the expedited path for the same request type triggers a review.

**Related Documents:** SOP-IT-001, SOP-IT-001-EDGE-B
