## Purpose

This SOP defines the standard procedure for **software license procurement procedure** within the Procurement / Purchasing department at MK-INFINITE-AI PRIVATE LIMITED, ensuring the process is followed consistently, is auditable, and meets the department's service expectations.

## Scope

This procedure applies to all requesters and any employee across MK-Infinite-AI who needs to initiate a **Software License Request** request. It covers the full workflow from initiation through to closure in MK-ProcureX.

## Applicable Roles

- Primary actor: **requester**
- Approver: **Procurement Lead**
- System of record: **MK-ProcureX**

## Preconditions

- The requester has an active MK-Infinite-AI account and access to MK-ProcureX.
- Number of seats, license term, and IT/Security review status must be available before starting this procedure.

## Required Information

- Employee ID and department
- Details of the software license request being requested
- Any supporting documentation required for approval

## Procedure

**Step 1:** the requester logs into MK-ProcureX and navigates to the 'Software License Request' section.

**Step 2:** the requester selects 'New Software License Request' and enters the required details, including number of seats, license term, and IT/Security review status.

**Step 3:** the requester attaches any supporting documentation and reviews the entry for accuracy before submitting.

**Step 4:** the requester submits the Software License Request; MK-ProcureX automatically routes it to the Procurement Lead for review.

**Step 5:** The Procurement Lead reviews the request against company policy and either approves, rejects, or returns it for clarification.

**Step 6:** On approval, MK-ProcureX updates the status to 'Approved' and notifies the requester by email/in-app notification.

**Step 7:** The approved Software License Request is processed and the record is retained in MK-ProcureX for audit purposes. All new software licenses require IT and Security sign-off before purchase.

## Expected Result

The software license request is completed, logged in MK-ProcureX, and the requester is notified of the outcome. The record remains available in MK-ProcureX for future reference and audit.

## Exceptions

- All new software licenses require IT and Security sign-off before purchase.
- Requests that do not meet the preconditions above are returned to the requester with an explanation rather than being rejected outright.

## Escalation Procedure

If the request is not actioned within the expected timeframe, escalate in this order: Procurement Executive → Procurement Specialist → Procurement Manager → Procurement Director. Escalations should reference the SOP-PROC-009 document ID and the relevant ticket/request number.
