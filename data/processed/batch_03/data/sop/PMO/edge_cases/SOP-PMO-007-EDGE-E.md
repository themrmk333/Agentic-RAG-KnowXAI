## Situation
Project Manager submits a project closure report request in MK-PMTrack that is missing required supporting information, or contains incorrect details (wrong amount, wrong employee, wrong date).

## Detection
The PMO Director reviewing the request in MK-PMTrack notices a required field is blank, a required attachment is missing, or the details don't reconcile with other records (e.g., an amount that doesn't match the attached receipt).

## Decision Criteria
The PMO Director decides whether the gap is minor enough to request a quick correction, or serious enough that the request should be rejected outright and resubmitted from scratch.

## Steps

1. The PMO Director does not approve or silently correct the request themselves; they return it to Project Manager in MK-PMTrack with a specific note on what's missing or wrong.
2. Project Manager is notified automatically and has a defined window (typically 5 business days) to correct and resubmit before the request is auto-closed as abandoned.
3. Project Manager corrects the specific issue identified — not a wholesale re-submission — and resubmits, keeping the same request thread rather than opening a new one.
4. The PMO Director reviews only the corrected fields on resubmission rather than re-reviewing the entire request from zero, to keep turnaround fast.
5. If the same requester repeatedly submits incomplete requests (3+ times in a quarter), the PMO Director flags this to the requester's manager for a coaching conversation.
6. Once complete and accurate, the request proceeds through the standard approval procedure in SOP-PMO-007.
