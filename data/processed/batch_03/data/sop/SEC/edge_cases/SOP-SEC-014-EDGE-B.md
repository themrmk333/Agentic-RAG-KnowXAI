## Scenario
A genuine business emergency requires the privileged access request to be actioned faster than the standard SOP allows, and waiting for the full standard approval chain would cause material harm (e.g., a production outage, a compliance deadline, or a safety issue).

## Deviation Procedure

1. requester clearly documents why the standard timeline in SOP-SEC-014 cannot be met, including the business impact of waiting.
2. requester contacts the Security Manager directly (not only via MK-SecGuard) — by phone or in-person — to request verbal pre-approval.
3. On verbal pre-approval, requester proceeds with the minimum necessary action to resolve the emergency, logging every action taken.
4. requester files the formal request in MK-SecGuard within 24 hours of the verbal approval, marked 'Emergency — Retroactive Approval'.
5. The Security Manager formally reviews and signs off on the retroactive request within 2 business days, confirming the emergency justification was reasonable.
6. If the Security Manager finds the emergency justification insufficient, the case is escalated to CISO for a policy-compliance review.

## Important Note
The expedited path is an exception, not a routine option — repeated use of this path for the same privileged access request type by the same requester is flagged for review by CISO.
