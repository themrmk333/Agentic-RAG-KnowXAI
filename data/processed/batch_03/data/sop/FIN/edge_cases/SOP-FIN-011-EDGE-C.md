**Related SOP:** SOP-FIN-011 (Fixed Asset Capitalization Procedure)  
**Department:** Finance & Accounting

## Situation
MK-Finance360 is down, in scheduled maintenance, or otherwise unreachable, but the asset capitalization genuinely cannot wait until the system is restored.

## Detection
Accountant attempts to log into MK-Finance360 and receives a system-unavailable error, or has received a maintenance notification covering the relevant window (see the Communications archive).

## Decision Criteria
Accountant first checks whether the request is time-sensitive enough to justify an off-system workaround, or whether it can simply wait for MK-Finance360 to be restored (the default expectation).

## Steps

1. Accountant confirms MK-Finance360 is genuinely unavailable (not just a personal connectivity issue) by checking with a colleague or the IT status page.
2. For non-urgent asset capitalization requests, Accountant waits for MK-Finance360 to be restored and submits normally — this is the default and preferred path.
3. For genuinely urgent requests, Accountant documents the request details (who, what, why, when) in an email to the Finance Manager instead of the system.
4. The Finance Manager reviews the emailed request using the same criteria they would apply inside MK-Finance360, and replies with an approval/rejection decision in writing.
5. Once MK-Finance360 is restored, Accountant or the Finance Manager re-enters the request and its outcome into MK-Finance360 retroactively, referencing the original email for the audit trail.
6. MK-Finance360's record is tagged 'Entered Retroactively — System Outage' so reporting doesn't mistake the entry date for the actual request date.

## Responsible Role
Accountant

## Approval
Finance Manager

## Escalation
Accountant -> Finance Lead -> Finance Manager -> Finance Director

## Expected Result
The asset capitalization is actioned without waiting for system restoration when genuinely urgent, while still ending up fully and correctly recorded in MK-Finance360 once it's back online.
