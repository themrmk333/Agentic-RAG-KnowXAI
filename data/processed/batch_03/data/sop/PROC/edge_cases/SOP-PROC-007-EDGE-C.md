**Department:** Procurement / Purchasing

## Situation
MK-ProcureX is down, in scheduled maintenance, or otherwise unreachable, but the vendor performance review genuinely cannot wait until the system is restored.

## Detection
Vendor Manager attempts to log into MK-ProcureX and receives a system-unavailable error, or has received a maintenance notification covering the relevant window (see the Communications archive).

## Decision Criteria
Vendor Manager first checks whether the request is time-sensitive enough to justify an off-system workaround, or whether it can simply wait for MK-ProcureX to be restored (the default expectation).

## Steps

1. Vendor Manager confirms MK-ProcureX is genuinely unavailable (not just a personal connectivity issue) by checking with a colleague or the IT status page.
2. For non-urgent vendor performance review requests, Vendor Manager waits for MK-ProcureX to be restored and submits normally — this is the default and preferred path.
3. For genuinely urgent requests, Vendor Manager documents the request details (who, what, why, when) in an email to the Procurement Manager instead of the system.
4. The Procurement Manager reviews the emailed request using the same criteria they would apply inside MK-ProcureX, and replies with an approval/rejection decision in writing.
5. Once MK-ProcureX is restored, Vendor Manager or the Procurement Manager re-enters the request and its outcome into MK-ProcureX retroactively, referencing the original email for the audit trail.
6. MK-ProcureX's record is tagged 'Entered Retroactively — System Outage' so reporting doesn't mistake the entry date for the actual request date.

## Responsible Role
Vendor Manager

## Approval
Procurement Manager

## Escalation
Procurement Executive -> Procurement Specialist -> Procurement Manager -> Procurement Director

## Expected Result
The vendor performance review is actioned without waiting for system restoration when genuinely urgent, while still ending up fully and correctly recorded in MK-ProcureX once it's back online.
