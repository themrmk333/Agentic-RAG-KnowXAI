# Human Resources — Advanced FAQs (Edge Cases, Comparisons, Policy Interpretation)

## FAQADV-HR-001: Leave Application Procedure: What happens if Reporting Manager is unavailable to approve a leave application?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Route it to the Reporting Manager's delegate (typically the next role up the escalation chain) via MK-HRMS, tagged 'Delegate Approval Required'; the Reporting Manager is notified on return and can flag it for review within 5 business days if needed.

**Related Documents:** SOP-HR-001-EDGE-A
---

## FAQADV-HR-002: Leave Application Procedure: Can a leave application be expedited in a genuine emergency?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Yes, via the expedited path: get verbal pre-approval from the Reporting Manager directly, proceed with the minimum necessary action, then file the formal request in MK-HRMS within 24 hours marked 'Emergency — Retroactive Approval'.

**Related Documents:** SOP-HR-001-EDGE-B
---

## FAQADV-HR-003: Leave Application Procedure: What do I do if MK-HRMS is down and I need to submit a leave application?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Non-urgent requests should wait for MK-HRMS to be restored. For genuinely urgent cases, email the Reporting Manager directly with the request details; once MK-HRMS is back, enter the request and outcome retroactively, tagged 'Entered Retroactively — System Outage'.

**Related Documents:** SOP-HR-001-EDGE-C
---

## FAQADV-HR-004: Leave Application Procedure: What happens if my leave application request is rejected, or I accidentally submit it twice?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** Rejections always come with a documented reason in MK-HRMS — correct the issue and resubmit, or escalate once if you disagree. Duplicates are flagged automatically and reconciled by keeping the original and closing the duplicate with a cross-reference.

**Related Documents:** SOP-HR-001-EDGE-D
---

## FAQADV-HR-005: Leave Application Procedure: What happens if my leave application submission is missing required documentation?
**Category:** Edge Case / What-If | **Difficulty:** Advanced | **Access Level:** employee

**Answer:** The Reporting Manager returns the request in MK-HRMS with a specific note on what's missing rather than approving or fixing it themselves; you have about 5 business days to correct and resubmit through the same request thread.

**Related Documents:** SOP-HR-001-EDGE-E
---

## FAQADV-HR-033: What's the difference between the standard Leave Application Procedure process and the emergency/expedited version?
**Category:** Comparison | **Difficulty:** Intermediate | **Access Level:** employee

**Answer:** The standard path (SOP-HR-001) goes through Reporting Manager via MK-HRMS in the normal order. The expedited path (SOP-HR-001-EDGE-B) is only for genuine emergencies: it requires verbal pre-approval first, immediate action, then retroactive formal filing within 24 hours — and repeated use of the expedited path for the same request type triggers a review.

**Related Documents:** SOP-HR-001, SOP-HR-001-EDGE-B
