## TCK3-LEGAL-00121 — Intellectual Property (P4, Closed)
**Created:** 2024-06-03 via Email  |  **Requester:** Rohan Singh  |  **Assigned to:** Ananya Desai

**Description:** Rohan Singh (Marketing) reported an issue via Email related to 'Intellectual Property Filing Procedure'. Category: Intellectual Property. Logged against MK-LegalVault.

**Investigation:** The assigned specialist reviewed the MK-LegalVault record, confirmed the reported symptom against 'Intellectual Property Filing Procedure', and checked recent related changes before identifying the cause below.

**Root Cause:** A budget/cost-centre code entered was inactive for the current fiscal period.

**Resolution:** Followed SOP-LEGAL-005 to resolve. the requester logs into MK-LegalVault and navigates to the 'IP Filing Request' section. the requester selects 'New IP Filing Request' and enters the required details, including invention/creative work description and prior art search results. the requester attaches any supporting documentation and reviews the entry for accuracy before submitting. the requester submits the IP Filing Request; MK-LegalVault automatically routes it to the General Counsel for review. The General Counsel reviews the request against company policy and either approves, rejects, or returns it for clarification.

**Verification:** The fix was verified against the original reported symptom before closing.

**Prevention:** Added a validation check to catch this class of issue automatically before submission.

**Related SOP:** SOP-LEGAL-005
