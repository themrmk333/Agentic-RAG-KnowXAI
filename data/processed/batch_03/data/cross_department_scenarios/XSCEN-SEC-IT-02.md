## Situation
IT rolls out a new productivity tool, and Security flags it days later as lacking proper data handling review.

## Resolution Steps

- Security immediately notifies IT and the tool is put on hold for new users pending review.
- IT and Security jointly assess actual risk: what data has already flowed through the tool, and how sensitive is it.
- If risk is low, Security fast-tracks a proper review so the rollout can resume with conditions.
- If risk is meaningful, IT pauses the rollout and works with Security and Legal to either remediate or replace the tool.
- The Software Installation Policy is reinforced: new tools require Security review before company-wide rollout, not after.

## Lesson
A rollout that skipped Security review is a process failure to fix going forward, independent of how the specific tool turns out.
