## Purpose

This SOP defines the standard procedure for **remote desktop / screen share support session** within the IT Support / Information Technology department at MK-INFINITE-AI PRIVATE LIMITED, ensuring the process is followed consistently, is auditable, and meets the department's service expectations.

## Scope

This procedure applies to all employees and any employee across MK-Infinite-AI who needs to initiate a **Remote Support Session** request. It covers the full workflow from initiation through to closure in MK-ServiceDesk.

## Applicable Roles

- Primary actor: **employee**
- Approver: **IT Support Engineer**
- System of record: **MK-ServiceDesk**

## Preconditions

- The requester has an active MK-Infinite-AI account and access to MK-ServiceDesk.
- Confirming the employee's consent before starting a remote session via MK-ServiceDesk Remote must be available before starting this procedure.

## Required Information

- Employee ID and department
- Details of the remote support session being requested
- Any supporting documentation required for approval

## Procedure

**Step 1:** the employee confirms the exact symptom, when it started, and whether it affects one system or several.

**Step 2:** the employee performs the standard first-line check: confirming the employee's consent before starting a remote session via MK-ServiceDesk Remote.

**Step 3:** If the issue persists, the employee applies the documented workaround for this issue type.

**Step 4:** the employee checks whether the issue is isolated to their own account/device or is affecting other users too.

**Step 5:** If still unresolved, the employee raises a ticket in MK-ServiceDesk categorised under 'Remote Support Session', attaching screenshots or error logs.

**Step 6:** The assigned specialist reproduces the issue, diagnoses the root cause, and applies a fix or a temporary workaround.

**Step 7:** the employee confirms the fix works; the ticket is closed in MK-ServiceDesk with the root cause logged. Remote sessions are logged and never used to access personal files without explicit consent.

## Expected Result

The remote support session is completed, logged in MK-ServiceDesk, and the requester is notified of the outcome. The record remains available in MK-ServiceDesk for future reference and audit.

## Exceptions

- Remote sessions are logged and never used to access personal files without explicit consent.
- Requests that do not meet the preconditions above are returned to the requester with an explanation rather than being rejected outright.

## Escalation Procedure

If the request is not actioned within the expected timeframe, escalate in this order: IT Support Engineer → IT Manager → IT Director. Escalations should reference the SOP-IT-014 document ID and the relevant ticket/request number.
